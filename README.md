# languages-playground

Hands-on code from my programming language tutorials: every example typed out, run, broken and fixed.
One folder per language or tool.

## Layout

| Folder | Inside |
|---|---|
| [`languages/`](languages/) | `c`, `cpp`, `python`, `rust`, `java`, `typescript`, `assembly` (x86 and ARM) |
| [`web/`](web/) | `php`, `node`, `react`, `nextjs`, `angular`, `flask`, `django` |
| [`databases/`](databases/) | `mysql`, `postgresql`, `mongodb` |
| [`servers/`](servers/) | `nginx`, `apache` |

Each language folder has its own short README: how to run the code, and what's done.
